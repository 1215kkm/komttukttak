자주 묻는 질문

설치해도 안전한가요?

설치 파일은 코드 서명을 마친 것만 공개합니다. 서명이 없는 파일은 배포하지 않으니, 윈도우가 '알 수 없는 게시자' 경고를 띄운다면 우리가 배포한 파일이 아닙니다.

앱은 디스크와 장치 정보를 읽어서 보여 줍니다. 파일이 생기는 건 리포트나 복구 파일을 내가 고른 폴더에 저장할 때뿐이고, 복구할 원본 드라이브에는 쓰지 않습니다. 검사 결과를 인터넷으로 보내는 기능은 없습니다. 앱이 인터넷에 접속하는 건 새 버전 확인·받기와 포토샵 도우미의 아이콘 받기(둘 다 내려받기만), 앱 안 안내 배너 받기(내려받기만), 그리고 처음 실행 때 동의한 경우에만 보내는 익명 사용 통계(어떤 기능을 썼는지 — 이름·파일·검사 결과 없음)입니다. 관리자 권한은 파일 복구의 [스캔 시작]을 누를 때만 윈도우가 한 번 묻습니다.

왜 무료인가요? 나중에 돈 받나요?

17개 기능은 계속 무료입니다. 수익은 검사 결과가 '수리·교체가 필요하다'로 나올 때만 나오는 연결에서 납니다. 예를 들어 HDD 검진이 🔴 위험이면 복구업체 견적 버튼이 보이고, 그 연결에서 소개 수수료를 받습니다. 🟢🟡일 때는 아무 버튼도 없습니다.

컴퓨터실용 16번 기능은 유료 교실관리 프로그램 CrownyClass의 입구입니다. 어느 쪽이든 결과를 부풀려서 버튼을 누르게 만들지 않습니다 — 그러면 다음 추천이 끊기니까요.

업데이트는 어떻게 되나요?

앱이 실행될 때 GitHub Releases에 새 버전이 있는지 확인하고, 있으면 조용히 받아 다음 실행에 적용합니다. 따로 눌러야 할 것은 없습니다.

받은 파일의 서명을 확인해 서명이 다르거나 버전이 낮은 파일은 설치하지 않습니다. 오프라인이면 업데이트만 건너뛰고 앱은 그대로 동작합니다.
