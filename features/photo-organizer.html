컴퓨터 사진 정리하는 법 (수만 장, 날짜별로) — 컴뚝딱

탐색기 그룹화·사진 앱으로 날짜별 정리하는 법과, 컴뚝딱 사진 정리(출시 예정)의 날짜·장소·유사 사진 묶기. 사진은 업로드하지 않습니다.

이런 상황이면

  • 폰에서 옮긴 사진 3만 장이 폴더 하나에 들어 있다.
  • 같은 장면 연사가 50장.
  • 언제 찍은 건지 파일명만 봐선 모른다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

찍은 날짜는 사진 파일 안에 이미 적혀 있습니다. 그걸로 묶기만 하면 됩니다.

  1. 탐색기 → 보기 → 그룹화 → '찍은 날짜'.
  2. Windows 사진 앱: 폴더를 추가하면 날짜별 타임라인으로 보입니다.
  3. 폰 사진의 위치: 파일 우클릭 → 속성 → 자세히 → GPS.
  4. 연사·중복은 '크기' 정렬로 비슷한 크기끼리 모아 보기.

보는 건 되는데 폴더로 옮기는 건 손입니다. 3만 장이면 손으로는 끝이 안 납니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 '사진 정리'는 출시 예정입니다.

  • 날짜·장소(GPS)·유사 장면별로 폴더 제안 — 옮기기 전 미리보기
  • 인물 분류는 PC 안에서 도는 로컬 모델만 사용, 사진은 어디에도 올리지 않습니다
  • 원본은 건드리지 않고 복사본으로 정리하는 옵션

자동 분류는 틀릴 수 있습니다. 자동으로 지우는 기능은 넣지 않습니다.
