준비중06 · PC 이사

새 컴퓨터로 데이터 옮기는 법 — 컴뚝딱

기존 PC에서 새 PC로 문서·사진·설정을 옮기는 윈도우 기본 방법(Windows 백업·OneDrive·외장 드라이브)과 컴뚝딱 PC 이사(출시 예정).

이런 상황이면

  • 새 PC를 샀는데 예전 파일·즐겨찾기·바탕화면을 어떻게 옮기나.
  • 외장하드로 복사하다 빠뜨린 폴더가 꼭 하나 있다.
  • 프로그램 설정까지 같이 가져가고 싶다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

Microsoft 계정이 있으면 반은 윈도우가 해 줍니다.

  1. Windows 백업 (설정 → 계정 → Windows 백업): 폴더·설정·앱 목록을 계정에 저장 → 새 PC 첫 설정에서 복원.
  2. OneDrive: 문서·사진·바탕화면 폴더 백업 켜기 → 새 PC에서 같은 계정으로 로그인.
  3. 외장 드라이브: C:\Users\내이름 폴더를 통째로 복사. AppData는 숨김 폴더라 '숨긴 항목 표시'가 필요합니다.
  4. 브라우저 즐겨찾기·비밀번호는 각 브라우저의 동기화 로그인이 가장 확실합니다.

빠뜨리는 건 늘 같은 곳입니다 — 다운로드 폴더, 바탕화면, 게임 세이브, 카톡 백업.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 'PC 이사'는 출시 예정입니다.

  • 같은 공유기 안 두 PC를 연결해 폴더를 골라 이전
  • 빠뜨리기 쉬운 곳(바탕화면·다운로드·AppData 일부·브라우저 프로필)을 체크리스트로
  • 옮긴 뒤 원본과 파일 수·용량을 대조해서 표시

설치된 프로그램 자체를 그대로 옮기는 건 라이선스·레지스트리 문제로 안 되는 경우가 많습니다. 설치 목록만 뽑아 드립니다.
