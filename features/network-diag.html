준비중08 · 인터넷 문제 진단기

인터넷 느리거나 끊길 때 원인 찾는 법 — 컴뚝딱

ping·DNS·공유기 재시작으로 와이파이·랜 문제가 PC인지 공유기인지 통신사인지 나누어 보는 법. 컴뚝딱 인터넷 문제 진단기(출시 예정).

이런 상황이면

  • 와이파이는 연결됐다는데 인터넷이 안 된다.
  • 게임만 끊긴다.
  • 통신사에 전화하면 "재부팅 해보세요"만 한다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

어디서 끊기는지를 나누는 게 전부입니다 — PC → 공유기 → 통신사 → DNS.

  1. cmd → ping 8.8.8.8 -n 10: 응답이 오면 회선은 정상. '요청 시간이 만료되었습니다'가 반복되면 공유기·회선 문제.
  2. ping google.com 은 안 되는데 위가 되면 DNS 문제 → 설정 → 네트워크 → 어댑터 → DNS 서버를 8.8.8.8 로.
  3. 공유기·모뎀 전원을 30초 끄고 켜기 — 가장 많은 문제가 여기서 끝납니다.
  4. 설정 → 네트워크 → 고급 네트워크 설정 → 네트워크 초기화 (마지막 수단, 재부팅 필요).

핑 결과를 읽는 것 자체가 낯설면, 그걸 그림으로 바꿔 주는 게 다음입니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 '인터넷 문제 진단기'는 출시 예정입니다.

  • PC → 공유기 → 통신사 → DNS 순서로 어디서 끊기는지 단계별 카드
  • 핑·패킷손실·Wi-Fi 신호를 1분 측정해 숫자로
  • 공유기 문제로 판정될 때만 공유기·통신·출장기사 안내

속도 측정 결과는 그 순간 값입니다. 한 번 측정으로 '회선이 나쁘다'고 말하지 않습니다.
