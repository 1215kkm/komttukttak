준비중12 · 파일 만능 변환기

HEIC·PDF·WebP 파일 변환하는 법 (무료, 업로드 없이) — 컴뚝딱

아이폰 HEIC를 JPG로, WebP를 PNG로, 문서를 PDF로 윈도우 기본 기능으로 바꾸는 법. 컴뚝딱 파일 만능 변환기(출시 예정)는 폴더째 PC 안에서 변환.

이런 상황이면

  • 아이폰 사진(HEIC)이 회사 PC에서 안 열린다.
  • 인터넷에서 받은 이미지가 WebP라 업로드가 안 된다.
  • 온라인 변환 사이트에 문서를 올리기가 찝찝하다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

한두 장이면 그림판으로 됩니다.

  1. HEIC → JPG: 그림판에서 열기 → 다른 이름으로 저장 → JPG. (열리지 않으면 Microsoft Store의 'HEIF 이미지 확장' 설치.)
  2. WebP → PNG: 그림판 또는 사진 앱에서 열고 PNG로 저장.
  3. 문서 → PDF: 인쇄 (Ctrl + P) → 'Microsoft Print to PDF'.
  4. 영상: Windows Clipchamp(기본 설치)로 열고 내보내기.

300장이면 그림판으로는 못 합니다. 폴더째 넣는 게 다음입니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 '파일 만능 변환기'는 출시 예정입니다.

  • 폴더째 끌어다 놓으면 한 번에 변환 — HEIC/WebP/PNG/JPG/PDF/영상/문서
  • 변환은 전부 PC 안에서. 어디에도 올리지 않습니다
  • 원본 보존, 변환본은 옆 폴더에

전문 그래픽·CAD 같은 특수 포맷은 범위 밖입니다. 되는 포맷 목록을 먼저 보여 드립니다.
