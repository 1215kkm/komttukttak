준비중03 · HDD 건강검진

하드디스크 건강 상태 확인하는 법 (SMART) — 컴뚝딱

PowerShell·chkdsk로 배드섹터와 SMART 상태를 보는 법, 컴뚝딱 HDD 건강검진(출시 예정)이 1분 만에 🟢🟡🔴 카드로 보는 법. 디스크를 읽기만 합니다.

이런 상황이면

  • 탐색기가 특정 폴더에서 멈추고, 복사 하나에 30분이 걸린다.
  • 부팅이 예전보다 눈에 띄게 오래 걸린다.
  • 5년 넘게 쓴 하드, 아직 괜찮은지 궁금하다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

쓰기 없이 상태만 보는 방법부터. 하드에서 '틱틱', '끼릭' 소리가 나면 어떤 검사도 돌리지 마세요 — 검사 자체가 디스크를 더 상하게 합니다.

  1. PowerShell(관리자): Get-PhysicalDisk | Select FriendlyName, MediaType, HealthStatus — Healthy면 정상, Warning/Unhealthy면 디스크가 스스로 경고 중.
  2. 더 자세히: Get-PhysicalDisk | Get-StorageReliabilityCounter | Select DeviceId, Temperature, ReadErrorsUncorrected, Wear — ReadErrorsUncorrected가 0이 아니면 못 읽은 구간이 있었다는 뜻.
  3. 이벤트 뷰어 (Win + R → eventvwr) → Windows 로그 → 시스템: 원본 'disk' 이벤트 7·51·153이 반복되면 같은 신호.
  4. chkdsk D: /f /r — 배드섹터 전체 스캔. 단, 디스크에 '쓰기'를 하므로 중요 파일을 백업한 뒤에. 1TB 하드면 2~4시간.

숫자가 나오긴 하는데 정상 범위가 어디까지인지가 문제죠. 그걸 카드 색으로 바꿔 주는 게 다음입니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 'HDD 건강검진'(출시 예정)은 버튼 한 번으로 SMART·온도·수명·위험도를 카드로 보여 줍니다.

  • 🟢 정상: 할 일 없습니다. 6개월 뒤 다시 보세요.
  • 🟡 주의: 중요 파일 백업 안내만. 그 이상은 없습니다.
  • 🔴 위험: 디스크가 '곧 실패할 수 있음'을 스스로 기록한 상태(SMART 예측 실패). 다음 할 일 순서와 복구업체 견적 버튼이 보입니다.
  • 관리자 권한은 검사 버튼을 누를 때만 묻고, 디스크는 읽기만 합니다.

"오늘 안에 죽습니다" 같은 시한 문장은 쓰지 않습니다. 디스크가 기록한 SMART 값을 그대로 보여 드립니다.
