지금 사용 가능02 · 파일 복구하기

삭제한 파일 복구하는 법 (무료) — 컴뚝딱

휴지통을 비운 파일을 윈도우 파일 기록·이전 버전·Windows File Recovery로 되살리는 법과, 컴뚝딱 파일 복구하기로 되는 것·안 되는 것.

이런 상황이면

  • 휴지통을 비웠는데 그 안에 필요한 파일이 있었다.
  • USB·외장하드를 꽂았더니 "포맷하시겠습니까?"가 뜬다.
  • 파일을 열면 "데이터 오류(순환 중복 검사)"가 나온다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

먼저, 지금 이 디스크에 아무것도 새로 저장하지 마세요. 지운 자리에 다른 파일이 덮어쓰이기 전까지는 살릴 수 있습니다.

  1. 휴지통: 아직 비우지 않았다면 파일 우클릭 → 복원.
  2. 파일 기록(File History)이 켜져 있었다면: 폴더 우클릭 → 속성 → '이전 버전' 탭.
  3. OneDrive를 쓰고 있다면: 웹 OneDrive의 휴지통에 30일간 보관됩니다.
  4. Windows File Recovery (Microsoft Store, 무료·명령줄): winfr C: D: /regular /n \Users\내이름\Documents\*.docx — 복구본은 반드시 다른 드라이브(D:)로.

명령줄이 낯설면 아래 컴뚝딱 방법으로 넘어가세요. 어느 쪽이든 그 디스크에 새로 저장만 하지 마세요.

2. 컴뚝딱으로 하는 법

컴뚝딱을 켜고 '파일 복구하기'를 누르면 세 단계입니다 — 삭제 파일 찾기 → 결과 → 저장.

  • 드라이브(NTFS 방식의 내장 드라이브·USB)를 고르고 사진·문서·영상·전체 중 찾을 종류 선택 → [스캔 시작]. 관리자 권한은 이때 한 번만 묻습니다
  • 지운 파일 기록에서 이름·경로를 찾고, 기록까지 지워진 사진·PDF·문서(docx·xlsx·pptx·hwpx)·mp4 는 파일 모양으로 한 번 더 찾습니다 (이 경우 이름은 되살리지 못합니다)
  • 파일마다 되살릴 가능성 3단계: 좋음(원래 그대로) · 일부만(열리지만 일부가 깨졌을 수 있음) · 낮음(이미 다른 파일이 덮어썼을 가능성이 큼)
  • 골라서 복구하면 다른 디스크의 폴더에만 새 파일로 저장합니다. 복구할 원본 드라이브에는 쓰지 않습니다

안 되는 것을 미리 말씀드립니다. 지운 뒤 그 드라이브에 새 파일을 많이 저장했으면 못 살릴 수 있어요. 헤드 손상·모터 고장·플래터 긁힘 같은 물리 손상도 소프트웨어로 안 됩니다. 하드에서 '틱틱' 소리가 나면 전원을 끄고 복구업체 견적부터 받으세요.

파일 복구하기, 설치하고 바로

설치 파일 4.5MB. 실행하면 첫 화면에서 '파일 복구하기'을 누르기만 하면 됩니다.

무료로 받기 설치 안내
  • 회원가입 없음
  • 광고 없음
  • 검사 결과 인터넷 전송 없음
