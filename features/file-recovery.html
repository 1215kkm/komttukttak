준비중02 · 파일 복구하기

삭제한 파일 복구하는 법 (무료) — 컴뚝딱

휴지통을 비운 파일을 윈도우 파일 기록·이전 버전·Windows File Recovery로 되살리는 법과, 컴뚝딱 파일 복구(출시 예정)가 되는 것·안 되는 것.

이런 상황이면

  • 휴지통을 비웠는데 그 안에 필요한 파일이 있었다.
  • USB·외장하드를 꽂았더니 "포맷하시겠습니까?"가 뜬다.
  • 파일을 열면 "데이터 오류(순환 중복 검사)"가 나온다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

먼저, 지금 이 디스크에 아무것도 새로 저장하지 마세요. 지운 자리에 다른 파일이 덮어쓰이기 전까지는 살릴 수 있습니다.

  1. 휴지통: 아직 비우지 않았다면 파일 우클릭 → 복원.
  2. 파일 기록(File History)이 켜져 있었다면: 폴더 우클릭 → 속성 → '이전 버전' 탭.
  3. OneDrive를 쓰고 있다면: 웹 OneDrive의 휴지통에 30일간 보관됩니다.
  4. Windows File Recovery (Microsoft Store, 무료·명령줄): winfr C: D: /regular /n \Users\내이름\Documents\*.docx — 복구본은 반드시 다른 드라이브(D:)로.

명령줄이 낯설면 여기서 멈추고 컴뚝딱 출시를 기다리셔도 됩니다. 그동안 그 디스크에 새로 저장만 하지 마세요.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 '파일 복구하기'는 출시 예정입니다. 나오면 이렇게 동작합니다.

  • 삭제 파일 스캔(파일시스템 메타·시그니처) → 미리보기 → 다른 드라이브로 복구
  • 배드섹터가 있는 디스크는 읽히는 부분만 먼저 이미지로 뜨고, 불량 구간은 나중에 재시도 (ddrescue 방식)
  • 고장 디스크에는 절대 쓰지 않습니다. 항상 다른 드라이브로 이미지를 뜬 뒤 그 이미지에서 복구

안 되는 것을 미리 말씀드립니다. 헤드 손상·모터 고장·플래터 긁힘 같은 물리 손상은 소프트웨어로 안 됩니다. 하드에서 '틱틱' 소리가 나면 전원을 끄고 복구업체 견적부터 받으세요.
