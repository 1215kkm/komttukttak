내 PC 사양 확인하는 법 — 컴뚝딱

CPU·RAM·그래픽카드·SSD/HDD·윈도우 버전을 설정·dxdiag·msinfo32·작업 관리자로 보는 법과, 컴뚝딱으로 3초 만에 한 화면·카드 한 장으로 보는 법.

이런 상황이면

  • 게임 사양 되는지 물어보려는데 내 컴퓨터 사양을 모른다.
  • 중고로 팔려고 글 쓰는데 그래픽카드 이름을 어디서 보는지 모르겠다.
  • 수리기사님이 "사양 좀 알려주세요" 하는데 화면 어디를 봐야 할지 막막하다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

윈도우에 이미 들어 있는 네 가지 방법입니다. 설치 없이, 무료.

  1. 설정 → 시스템 → 정보 (Win + I): 프로세서(CPU), 설치된 RAM, 윈도우 버전. 그래픽카드는 여기 없습니다.
  2. dxdiag (Win + R → dxdiag): '디스플레이' 탭에 그래픽카드 이름과 메모리. 게임 사양 물을 때 가장 많이 쓰는 화면.
  3. msinfo32 (Win + R → msinfo32): 메인보드 제조사·모델, BIOS 버전. 램 슬롯 확인할 때.
  4. 작업 관리자 (Ctrl + Shift + Esc) → 성능: '디스크'에서 SSD/HDD 종류, '메모리'에서 속도와 슬롯 사용 개수.

CPU·RAM은 어디서든 보이지만 그래픽카드는 dxdiag, 메인보드는 msinfo32, SSD 여부는 작업 관리자 — 네 군데를 돌아야 다 모입니다. 캡처해서 보내려면 네 장이죠.

2. 컴뚝딱으로 하는 법

컴뚝딱을 켜고 '내 PC 사양 보기'를 누르면 위 네 화면의 내용이 한 화면에 나옵니다.

  • CPU·RAM·그래픽카드·저장장치(SSD/HDD)·윈도우 버전·IP·PC 이름
  • 텍스트로 복사 → 카톡·게시판에 그대로 붙이기 (캡처 네 장 대신 복사 한 번)
  • 설치 프로그램 탭: 이 PC 에 깔린 프로그램 목록과 버전, 이름 일부만 쳐도 찾는 "이 프로그램 있나요?" 확인 (예: "한글" → 한컴오피스 한글)
  • 이미지 카드 저장은 다음 버전에서 열립니다

사양 보기는 읽기만 합니다. 관리자 권한도 필요 없고, 결과는 PC 밖으로 나가지 않습니다.

내 PC 사양 보기, 설치하고 바로

설치 파일 4.5MB. 실행하면 첫 화면에서 '내 PC 사양 보기'을 누르기만 하면 됩니다.

무료로 받기 설치 안내
  • 회원가입 없음
  • 광고 없음
  • 검사 결과 인터넷 전송 없음
