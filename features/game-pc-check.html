준비중14 · 게임 PC 진단기

게임 프레임 떨어질 때 원인 찾는 법 — 컴뚝딱

게임 바·작업 관리자·온도로 FPS 저하의 병목(CPU/GPU/RAM/온도/드라이버)을 찾는 법. 컴뚝딱 게임 PC 진단기(출시 예정).

이런 상황이면

  • 예전엔 잘 되던 게임이 갑자기 끊긴다.
  • 그래픽카드를 바꿔야 하는지 램을 늘려야 하는지 모르겠다.
  • 노트북이 뜨거워지면 느려진다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

게임 중에 CPU와 GPU 중 뭐가 100%인지만 보면 병목이 나옵니다.

  1. 게임 바 (Win + G) → 성능 위젯: 게임 중 CPU·GPU·RAM 사용률과 FPS.
  2. GPU 100%·CPU 여유 = 그래픽카드 병목 / CPU 100%·GPU 여유 = CPU 병목 / RAM 90% 이상 = 메모리 부족.
  3. 온도: 작업 관리자 → 성능 → GPU 온도. 85°C 이상이 계속되면 먼지·서멀 문제.
  4. 그래픽 드라이버: 제조사(NVIDIA/AMD/Intel) 앱에서 최신으로.

게임하면서 숫자 네 개를 동시에 보는 게 문제죠. 기록해 뒀다가 보는 게 다음입니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 '게임 PC 진단기'는 출시 예정입니다.

  • 게임 실행 중 1분 기록 → 병목이 어디인지 카드 한 장
  • 온도·스로틀링(과열로 속도 제한) 여부 표시
  • 부품 업그레이드가 답일 때만 어떤 부품인지 안내

"이 부품 사면 FPS 2배" 같은 수치 약속은 하지 않습니다.
