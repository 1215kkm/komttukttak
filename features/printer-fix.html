준비중15 · 프린터 해결사

프린터 인쇄 안 될 때 해결하는 법 — 컴뚝딱

인쇄 대기열 막힘·오프라인 표시·드라이버 문제를 윈도우 기본 기능으로 푸는 순서. 컴뚝딱 프린터 해결사(출시 예정).

이런 상황이면

  • '인쇄 중'인데 아무것도 안 나온다.
  • 프린터가 '오프라인'으로 표시된다.
  • 어제까지 되던 무선 프린터가 안 잡힌다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

열에 여덟은 대기열이 막힌 겁니다. 그것부터.

  1. 설정 → Bluetooth 및 장치 → 프린터 및 스캐너 → 해당 프린터 → 인쇄 대기열 열기 → 모든 문서 취소.
  2. 그래도 막히면: 서비스 (Win + R → services.msc) → Print Spooler 우클릭 → 다시 시작.
  3. '오프라인': 프린터 전원·Wi-Fi 재연결 후 프린터 속성 → '오프라인으로 프린터 사용' 해제.
  4. 설정 → 시스템 → 문제 해결 → 기타 문제 해결사 → 프린터 실행.

이 순서를 외우기 싫으면 버튼 하나로 묶는 게 다음입니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 '프린터 해결사'는 출시 예정입니다.

  • 연결·드라이버·대기열 세 가지를 순서대로 자동 점검
  • 스풀러 재시작·대기열 비우기는 버튼 하나
  • 토너·잉크 부족이면 어떤 카트리지인지 표시

프린터 기종별 펌웨어 문제는 제조사 영역입니다. 그땐 그렇게 말씀드립니다.
