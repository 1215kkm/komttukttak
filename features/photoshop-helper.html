포토샵 반복 작업 줄이는 법 (선택 영역 저장·SNS 크기·분할 저장) — 컴뚝딱

포토샵 액션 녹화와 일괄 처리로 선택 영역 저장·크기 변환·워터마크를 하는 법과, 컴뚝딱 포토샵 도우미로 분할 저장·레이어 자동 정리까지 무료로 하는 법.

이런 상황이면

  • 인스타·유튜브·블로그마다 크기가 달라 같은 사진을 세 번 저장한다.
  • 선택 영역을 잡아 PNG 로 빼내는 일을 하루에 스무 번 한다.
  • 로고를 늘 같은 자리·같은 크기로 넣어야 하는데 매번 눈대중이다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

포토샵에 들어 있는 액션(Action)과 일괄 처리로 어느 정도는 됩니다. 설치할 것은 없습니다.

  1. 액션 녹화: 창 > 액션 → 새 액션 → 기록(빨간 점) → 할 일을 한 번 직접 하고 정지. 다음부터는 재생 버튼 하나.
  2. 여러 장에 같은 액션: 파일 > 자동화 > 일괄 처리(Batch)에서 폴더와 액션을 고릅니다.
  3. 크기 변환: 이미지 > 이미지 크기(Alt + Ctrl + I). 비율을 유지한 채 긴 변 기준으로 맞춥니다.
  4. 선택 영역만 저장: 선택 → Ctrl + C → 파일 > 새로 만들기(클립보드 크기로 열립니다) → 붙여넣고 저장.

액션은 같은 순서에는 강하지만, 이번엔 정사각형·다음엔 세로형처럼 조건이 바뀌면 액션을 여러 개 만들어 관리하게 됩니다.

2. 컴뚝딱으로 하는 법

컴뚝딱을 켜고 '포토샵 도우미'를 누르면 기능 카드가 한 화면에 나옵니다. 포토샵 [파일 > 스크립트] 메뉴에 깔리는 건 컴뚝딱을 여는 실행기 하나뿐입니다. 값 정하기·미리보기·여러 장 처리는 전부 컴뚝딱 안에서 돌고, 포토샵 메뉴에서 눌러도 컴뚝딱이 앞으로 나오면서 그 기능 화면이 열립니다.

  • 포토샵 문서에서 바로
  • 선택 영역 저장 잡아 둔 선택 영역만 PNG·JPG 파일로 빼냅니다. 저장할 때 폴더를 훑어 다음 번호로 이어 줍니다.
  • 선택 영역 안 내용 지우기 사진 위 글자·잡동사니를 지우고 주변 배경으로 메웁니다(내용 인식 채우기). Ctrl + Z 한 번이면 되돌아갑니다.
  • 분할 저장 눈금자 가이드대로 긴 상세페이지를 위에서 아래로 잘라 번호대로 저장합니다. 800 × 6000 문서를 4조각으로 나눠 봤을 때 6초 걸렸습니다.
  • 레이어 자동 정리 흩어진 레이어를 구간별·종류별·이름별 그룹으로 묶습니다. 미리 만들어 둔 그룹은 그대로 두고, Ctrl + Z 한 번에 통째로 되돌아옵니다.
  • 배경 지우기 (누끼) AI 가 색이 아니라 모양을 보고 배경만 지웁니다. 배경과 제품 색이 비슷해도 제품이 남습니다. AI 는 처음 쓸 때 한 번 받고(185MB), 사진은 PC 안에서만 처리합니다.
  • 글자·글꼴 한 번에 바꾸기 가격·날짜 같은 문구를 문서 전체에서 한 번에 바꾸고, 이 PC 에 없는 글꼴을 있는 글꼴로 바꿉니다. 쓰인 글자 크기가 몇 가지인지, 어떤 글이 몇 크기인지도 한 줄씩 정리해 줍니다.
  • 레이어 색 한 번에 바꾸기 여러 레이어에 쓰인 같은 색을 원하는 색으로 한 번에 바꿉니다.
  • 모자이크·가리기 고른 얼굴·전화번호·주소를 모자이크·흐리게·검정 막대로 가립니다.
  • 잡티 지우기 도우미 고른 잡티를 지우고 피부 톤을 부드럽게 합니다. 세밀한 곳은 포토샵에서 손이 들어갑니다.
  • 사진 여러 장 한 번에 (포토샵 없이도)
  • SNS 크기로 만들기 인스타 정사각·세로·스토리, 유튜브 썸네일, 스마트스토어, 블로그 가로 규격으로 여러 장을 한 번에 만듭니다.
  • 정사각 만들기 500 × 500, 1000 × 1000 처럼 정사각으로 맞춥니다. 여백 색도 고릅니다.
  • 워터마크·로고 넣기 로고나 글자를 여러 장에 같은 자리·같은 크기로 넣습니다.
  • 필터 입히기 선명하게·뽀얗게·흑백·따뜻하게 같은 느낌을 여러 장에 한 번에.
  • 이미지 길게 이어붙이기 여러 장을 위아래로 이어 상세페이지 한 장으로 만듭니다.
  • 확장자 바꾸기 webp·png·jpg·bmp·gif 끼리, wav ↔ mp3, PDF → JPG·PNG (쪽마다 한 장씩 또는 전체를 이어 한 장으로). 저장 폴더도 고릅니다.
  • 꾸미기
  • 배경 템플릿 만들기 단색·그라데이션·문양·줄무늬·점무늬 배경을 원하는 크기로. 색만 정하면 됩니다.
  • 아이콘·스티커 넣기 화살표·폭죽·버튼 같은 아이콘을 골라 정한 자리에 같은 크기로 얹습니다.
  • GIF 슬롯머신 만들기 번호가 돌다가 정한 번호에서 멈추는 움직이는 이미지를 만듭니다.
  • 편하게 쓰기
  • 포토샵 옆에 붙여 쓰기 포토샵 오른쪽·왼쪽이나 아래에 띠로 붙어 버튼만 보입니다. 창을 번갈아 찾지 않아도 됩니다.
  • 포토샵과 같이 켜기 포토샵을 켜면 컴뚝딱도 같이 켜지고 옆에 저절로 붙습니다.
  • 내가 사용한 단축키 포토샵에서 누른 단축키가 설명과 함께 뜹니다. 핀으로 고정하면 맨 위에서 눌러 바로 실행됩니다.
  • 구글 드라이브 보관함 작업 파일을 내 구글 드라이브에 올리고 받습니다. 남은 용량도 보여 줍니다.
  • 전부 무료 지금 열려 있는 기능은 전부 무료이고, 나중에 유료로 바꾸지 않습니다.

안 되는 것을 미리 말씀드립니다. AI 누끼도 머리카락 한 올·털·투명한 유리처럼 아주 가는 곳은 깔끔하지 않을 수 있어 포토샵에서 다듬어야 할 수 있습니다. 얼굴 잡티 제거는 도우미라 포토샵에서 손이 들어갑니다. 포토샵에 붙는 동작은 포토샵 CS6 이상에서 되고, 크기 변환·배경 템플릿·GIF 는 포토샵이 없어도 컴뚝딱 안에서 됩니다. 아이콘을 받을 때 인터넷에 접속하며 무엇이 오가는지는 개인정보처리방침 2번에 적었습니다.

포토샵 도우미, 설치하고 바로

설치 파일 4.5MB. 실행하면 첫 화면에서 '포토샵 도우미'을 누르기만 하면 됩니다.
