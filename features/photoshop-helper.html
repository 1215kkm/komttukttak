준비중17 · 포토샵 도우미

포토샵에서 같은 작업 반복할 때 (선택 영역 저장·SNS 크기 변환) — 컴뚝딱

포토샵의 선택 영역 저장, 크기 변환, 워터마크, 배경 만들기를 액션 녹화와 일괄 처리로 하는 법과, 컴뚝딱 포토샵 도우미(출시 예정)가 [파일 > 스크립트] 메뉴에서 같은 일을 하는 법.

이런 상황이면

  • 인스타·유튜브·블로그마다 크기가 달라 같은 사진을 세 번 저장한다.
  • 선택 영역을 잡아 PNG 로 빼내는 일을 하루에 스무 번 한다.
  • 로고를 늘 같은 자리·같은 크기로 넣어야 하는데 매번 눈대중이다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

포토샵에 들어 있는 액션(Action)과 일괄 처리로 어느 정도는 됩니다. 설치할 것은 없습니다.

  1. 액션 녹화: 창 > 액션 → 새 액션 → 기록(빨간 점) → 할 일을 한 번 직접 하고 정지. 다음부터는 재생 버튼 하나.
  2. 여러 장에 같은 액션: 파일 > 자동화 > 일괄 처리(Batch)에서 폴더와 액션을 고릅니다.
  3. 크기 변환: 이미지 > 이미지 크기(Alt + Ctrl + I). 비율을 유지한 채 긴 변 기준으로 맞춥니다.
  4. 선택 영역만 저장: 선택 → Ctrl + C → 파일 > 새로 만들기(클립보드 크기로 열립니다) → 붙여넣고 저장.

액션은 같은 순서에는 강하지만, 이번엔 정사각형·다음엔 세로형처럼 조건이 바뀌면 액션을 여러 개 만들어 관리하게 됩니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 '포토샵 도우미'는 준비 중입니다. 앱이 포토샵의 [파일 > 스크립트] 메뉴에 컴뚝딱 항목을 설치해 두고, 앱 화면에서도 같은 동작을 부를 수 있게 하는 기능입니다.

  • 선택 영역 저장 — 지금 잡아 둔 선택 영역만 PNG/JPG 파일로 빼내기
  • 선택 영역 안 내용 지우기 — 안에서 여러 단계를 거쳐도 포토샵 히스토리에는 한 칸으로 남아 Ctrl + Z 한 번이면 되돌아갑니다
  • SNS 크기 변환 — 인스타 정사각·세로·스토리, 유튜브 썸네일, 스마트스토어, 블로그 가로 같은 규격으로 여러 장 한 번에
  • 워터마크 — 로고나 글자를 여러 장에 같은 자리·같은 크기로
  • 배경 템플릿 — 단색·그라데이션·패턴 배경을 원하는 크기로 만들기
  • 아이콘 넣기 — 아이콘·로고를 정한 자리에 같은 크기로 배치

준비 중인 기능입니다. 포토샵에 붙는 동작은 포토샵 CS6 이상에서 되고, 크기 변환과 배경 만들기는 포토샵이 없어도 컴뚝딱 안에서 됩니다. 아이콘을 받을 때 인터넷에 접속하며 무엇이 오가는지는 개인정보처리방침 2번에 적었습니다.
