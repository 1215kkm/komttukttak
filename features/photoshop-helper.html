지금 사용 가능17 · 포토샵 도우미

포토샵 반복 작업 줄이는 법 (선택 영역 저장·SNS 크기·분할 저장) — 컴뚝딱

포토샵 액션 녹화와 일괄 처리로 선택 영역 저장·크기 변환·워터마크를 하는 법과, 컴뚝딱 포토샵 도우미로 분할 저장·레이어 자동 정리까지 무료로 하는 법.

이런 상황이면

  • 인스타·유튜브·블로그마다 크기가 달라 같은 사진을 세 번 저장한다.
  • 선택 영역을 잡아 PNG 로 빼내는 일을 하루에 스무 번 한다.
  • 로고를 늘 같은 자리·같은 크기로 넣어야 하는데 매번 눈대중이다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

포토샵에 들어 있는 액션(Action)과 일괄 처리로 어느 정도는 됩니다. 설치할 것은 없습니다.

  1. 액션 녹화: 창 > 액션 → 새 액션 → 기록(빨간 점) → 할 일을 한 번 직접 하고 정지. 다음부터는 재생 버튼 하나.
  2. 여러 장에 같은 액션: 파일 > 자동화 > 일괄 처리(Batch)에서 폴더와 액션을 고릅니다.
  3. 크기 변환: 이미지 > 이미지 크기(Alt + Ctrl + I). 비율을 유지한 채 긴 변 기준으로 맞춥니다.
  4. 선택 영역만 저장: 선택 → Ctrl + C → 파일 > 새로 만들기(클립보드 크기로 열립니다) → 붙여넣고 저장.

액션은 같은 순서에는 강하지만, 이번엔 정사각형·다음엔 세로형처럼 조건이 바뀌면 액션을 여러 개 만들어 관리하게 됩니다.

2. 컴뚝딱으로 하는 법

컴뚝딱을 켜고 '포토샵 도우미'를 누르면 기능 카드가 한 화면에 나옵니다. 포토샵 [파일 > 스크립트] 메뉴에 깔리는 건 컴뚝딱을 여는 실행기 하나뿐입니다. 값 정하기·미리보기·여러 장 처리는 전부 컴뚝딱 안에서 돌고, 포토샵 메뉴에서 눌러도 컴뚝딱이 앞으로 나오면서 그 기능 화면이 열립니다.

  • 선택 영역 저장 — 지금 잡아 둔 선택 영역만 PNG/JPG 파일로 빼내기. 저장할 때 폴더를 훑어 다음 번호로 이어 줍니다
  • 선택 영역 안 내용 지우기 — 내용 인식 채우기로 주변 배경을 메웁니다. 안에서 여러 단계를 거쳐도 포토샵 히스토리에는 한 칸으로 남아 Ctrl + Z 한 번이면 되돌아갑니다
  • 분할 저장 — 눈금자 가이드를 만들어 긴 그림을 위에서 아래로 잘라 한 번에 저장. 800 × 6000 문서를 1500px 기준 4조각으로 나눠 봤을 때 6초 걸렸습니다
  • 레이어 자동 정리 — 가이드 구간별·종류별·이름 앞말별 세 방식으로 그룹 묶기. 미리보기로 먼저 보고, 적용한 뒤에는 Ctrl + Z 한 번에 통째로 되돌아옵니다. 클리핑 마스크가 깨지지 않는 것은 픽셀 대조로 확인했습니다 (96만 픽셀 중 다른 픽셀 0개)
  • SNS 크기 변환 — 인스타 정사각·세로·스토리, 유튜브 썸네일, 스마트스토어, 블로그 가로 같은 규격으로 여러 장 한 번에. 500 × 500, 1000 × 1000 같은 정사각도 같은 자리에서
  • 워터마크 — 로고나 글자를 여러 장에 같은 자리·같은 크기로
  • 배경 템플릿·아이콘 넣기 — 단색·그라데이션·문양·줄무늬·점무늬 배경을 원하는 크기로, 분류별 아이콘은 정한 자리에 같은 크기로. 선명하게·뽀얗게·흑백 같은 필터도 여러 장 한 번에
  • 레이어 색 한 번에 바꾸기 — 여러 레이어에 쓰인 같은 색을 원하는 색으로 한 번에
  • 누끼(배경 지우기)·얼굴 잡티 제거는 도우미입니다 — 단색 배경은 앱이 지우고, 복잡한 배경과 잡티는 포토샵에서 손이 들어갑니다
  • GIF 슬롯머신 — 번호가 돌다가 정한 번호에서 멈추는 움직이는 이미지 만들기
  • 붙임 모드 — 포토샵 오른쪽에 세로 띠로 붙어 버튼만 보이고, 마우스를 올리면 펼쳐집니다. 창을 번갈아 찾지 않아도 됩니다
  • 지금 열려 있는 기능은 전부 무료이고, 나중에 유료로 바꾸지 않습니다

안 되는 것을 미리 말씀드립니다. 누끼(배경 지우기)와 얼굴 잡티 제거는 도우미입니다 — 단색 배경은 앱이 지우지만, 복잡한 배경·머리카락·털과 잡티는 포토샵에서 손이 들어갑니다. 포토샵에 붙는 동작은 포토샵 CS6 이상에서 되고, 크기 변환·배경 템플릿·GIF 는 포토샵이 없어도 컴뚝딱 안에서 됩니다. 아이콘을 받을 때 인터넷에 접속하며 무엇이 오가는지는 개인정보처리방침 2번에 적었습니다.

포토샵 도우미, 설치하고 바로

설치 파일 4.5MB. 실행하면 첫 화면에서 '포토샵 도우미'을 누르기만 하면 됩니다.
