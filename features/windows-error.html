준비중13 · Windows 오류 해결사

윈도우 오류 코드 해결하는 법 (블루스크린·업데이트 오류) — 컴뚝딱

블루스크린 정지 코드와 업데이트 오류 0x8007 계열을 이벤트 뷰어·sfc·DISM으로 푸는 순서. 컴뚝딱 Windows 오류 해결사(출시 예정).

이런 상황이면

  • 블루스크린 정지 코드를 찍어 뒀는데 뭘 검색해야 할지 모르겠다.
  • 업데이트가 0x80070002 로 계속 실패한다.
  • "이 앱을 시작할 수 없습니다"가 반복된다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

윈도우에는 자기 파일을 스스로 고치는 명령이 둘 있습니다. 그것부터.

  1. 블루스크린: 정지 코드(예: CRITICAL_PROCESS_DIED)를 그대로 검색. 이벤트 뷰어 → Windows 로그 → 시스템에서 오류 원본 확인.
  2. 시스템 파일 검사: cmd(관리자) → sfc /scannow.
  3. 그래도 안 되면: DISM /Online /Cleanup-Image /RestoreHealth 실행 후 sfc 를 다시.
  4. 업데이트 오류: 설정 → 시스템 → 문제 해결 → 기타 문제 해결사 → Windows 업데이트 실행.

여기까지 해도 반복되면 드라이버나 하드웨어 쪽입니다. 그 판정이 다음입니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 'Windows 오류 해결사'는 출시 예정입니다.

  • 오류 코드 입력 또는 이벤트 로그에서 자동 수집 → 원인 후보와 해결 순서
  • sfc·DISM 같은 안전한 수정은 버튼으로 (관리자 권한은 그때만)
  • 하드웨어 문제로 판정될 때만 원격·출장 수리 안내

레지스트리를 임의로 고치는 '자동 수정'은 넣지 않습니다. 되돌릴 수 있는 수정만 합니다.
