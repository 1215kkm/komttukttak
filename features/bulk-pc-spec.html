학생 PC 여러 대 사양 한 번에 확인하는 법 (컴퓨터실) — 컴뚝딱

컴퓨터실·학원 PC 20~40대의 사양·윈도우 버전·저장공간·설치 프로그램을 한 번에 보는 법. PowerShell 원격 조회와 컴뚝딱 PC 사양 일괄 확인(출시 예정).

이런 상황이면

  • 새 학기, 컴퓨터실 30대 중 어떤 PC가 아직 윈도우 10인지.
  • 학생 PC마다 돌아다니며 저장공간을 확인한다.
  • 프로그램이 설치 안 된 자리를 수업 시작하고서야 안다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

도메인(AD) 환경이면 PowerShell 원격 조회가 됩니다. 아니면 PC마다 돌아야 합니다.

  1. 각 PC에서 winver / 설정 → 저장소 확인 — 30대면 30번.
  2. 도메인 환경: PowerShell → Get-CimInstance Win32_ComputerSystem -ComputerName PC01,PC02 (원격 관리 WinRM 설정 필요).
  3. 설치 프로그램: Get-Package 결과 또는 설정 → 앱 목록을 PC마다 캡처.
  4. 결과를 엑셀에 손으로 정리.

학원·학교 컴퓨터실 대부분은 도메인이 없습니다. 그래서 2번이 안 되고, 1·3·4번을 30번 반복하게 됩니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 'PC 사양 일괄 확인'은 출시 예정입니다.

  • 같은 네트워크의 학생 PC를 찾아 사양·윈도우 버전·저장공간·IP·PC 이름·프로그램 설치 여부를 표 하나로
  • 엑셀(CSV)로 내보내기
  • 화면 보기·파일 전송·원격 도움이 필요하면 CrownyClass(교실관리 프로그램)로 이어집니다

학생 PC 정보를 모으는 기능이므로 학교·학원 관리자 PC에서만 사용하세요.
