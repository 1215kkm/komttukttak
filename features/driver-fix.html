드라이버 오류 해결하는 법 (장치 관리자 노란 느낌표) — 컴뚝딱

장치 관리자 노란 느낌표·오류 코드 28/43/10의 뜻과, 윈도우 업데이트·제조사 사이트·롤백으로 고치는 법. 컴뚝딱 드라이버 문제 해결사(출시 예정).

이런 상황이면

  • 장치 관리자에 노란 느낌표가 떠 있다.
  • 소리·와이파이·USB가 갑자기 안 된다.
  • '드라이버 자동 설치' 프로그램을 깔았더니 광고와 유료 결제만 나온다.

1. 윈도우 기본 기능으로 (무료·설치 없음)

제3자 '드라이버 업데이트 프로그램'은 피하세요. 윈도우와 제조사 사이트, 두 곳이면 됩니다.

  1. 장치 관리자 (Win + X → 장치 관리자): 느낌표 장치 우클릭 → 속성 → '장치 상태'의 코드 확인. 28 = 드라이버 없음, 43 = 장치 오류 보고, 10 = 시작 불가.
  2. 설정 → Windows 업데이트 → 고급 옵션 → 선택적 업데이트: 드라이버 항목이 있으면 설치.
  3. 제조사 사이트(노트북 모델명 / 메인보드 모델명으로 검색)에서 직접 받기.
  4. 최근에 고장났다면: 속성 → 드라이버 탭 → '드라이버 롤백'.

어느 장치가 어느 드라이버인지 이름부터 낯설다면, 그 식별이 다음 단계입니다.

2. 컴뚝딱으로 하는 법 (출시 예정)

컴뚝딱 '드라이버 문제 해결사'는 출시 예정입니다.

  • 오류 장치와 코드를 한글로 풀어서 보여 주기
  • 필요한 드라이버의 정확한 이름과 제조사 페이지 식별 (설치 파일을 대신 받아 오지는 않습니다)
  • 롤백이 가능한 경우 안내

출처 모를 드라이버 묶음을 자동 설치하지 않습니다. 잘못 깔린 드라이버는 부팅 실패까지 갑니다.
