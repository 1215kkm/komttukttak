설치할 때 파란 창(Windows의 PC 보호)이 뜨나요?

정상입니다. 아직 서명 인증서가 없는 새 프로그램이라 윈도우가 한 번 확인을 요청하는 것입니다. 아래 순서대로 하면 설치가 진행되고, 이후에는 다시 뜨지 않습니다.

왜 뜨나요

  • 윈도우는 만든 사람이 '코드 서명 인증서'로 서명하지 않은 설치 파일, 그리고 아직 많은 PC 에서 실행된 적이 없는 새 파일에 이 창을 띄웁니다. 파일이 나쁘다는 판정이 아니라 '아직 모르는 파일' 이라는 뜻입니다.
  • 컴뚝딱은 서명 인증서를 준비하는 중입니다(유료 발급). 인증서를 받아 서명한 버전이 나오면 이 창은 사라집니다.
  • 프로그램은 PC 사양·검사 결과를 인터넷으로 보내지 않습니다. 인터넷에 접속하는 경우는 두 가지 — 새 버전이 있는지 GitHub 에 확인할 때와, 포토샵 도우미에서 아이콘을 받을 때입니다. 둘 다 내려받기만 하고 올리지 않습니다. 자세한 내용은 개인정보처리방침에 적었습니다.
  • 설치 파일과 소스 코드는 GitHub 에 공개돼 있어 누구나 내용을 확인할 수 있습니다.

개인정보처리방침 · GitHub 레포 · GitHub Releases

넘기는 방법 — 3단계

  1. 파란 창에서 '추가 정보' 를 누릅니다
    창 가운데 작은 글씨 '추가 정보' 를 누르면 아래에 '실행' 버튼이 나타납니다. 처음엔 '실행 안 함' 버튼만 보여서 놓치기 쉽습니다.
  2. '실행' 을 누릅니다
    앱 이름이 komttukttak-setup.exe 인지 확인하고 '실행' 을 누릅니다. 이름이 다르면 다른 파일이니 실행하지 마세요.
  3. 설치가 이어집니다
    설치는 내 계정 폴더 안에만 이루어져 관리자 비밀번호를 묻는 창(사용자 계정 컨트롤)은 뜨지 않습니다. 끝나면 바탕화면과 시작 메뉴에 컴뚝딱이 생깁니다.

백신이 막을 때

Windows Defender·알약·V3 같은 백신이 서명 없는 새 파일을 '의심' 으로 잡거나 격리하는 일이 있습니다. 이럴 때는 아래를 확인해 주세요.

  • 받은 곳이 맞는지: 주소창이 github.com/1215kkm/komttukttak 으로 시작하는 GitHub Releases 페이지에서 받았는지 확인합니다. 다른 곳에서 받은 파일은 저희가 올린 파일이 아닐 수 있습니다.
  • 파일 이름이 komttukttak-setup.exe 인지 확인합니다.
  • 두 가지가 맞다면 백신의 격리함(검역소)에서 파일을 복원하고 '예외(신뢰) 목록' 에 추가한 뒤 다시 실행합니다. 방법은 백신마다 달라 백신 이름 + '예외 추가' 로 검색하면 나옵니다.
  • 그래도 찜찜하면 설치하지 않아도 됩니다. GitHub Issues 에 백신 이름과 표시된 판정명을 남겨 주시면 확인해서 답합니다.

삭제 방법

  • 윈도우 설정 → 앱 → 설치된 앱 에서 '컴뚝딱' 을 찾아 ⋯ → 제거. 또는 시작 메뉴에서 컴뚝딱을 마우스 오른쪽 버튼 → 제거.
  • 삭제하면 프로그램 파일이 지워집니다. 회원가입이 없으니 탈퇴할 계정도 없습니다.
  • 앱 설정 파일이 내 계정 폴더(AppData) 안에 남을 수 있습니다. 남기지 않으려면 파일 탐색기 주소창에 %APPDATA% 를 입력해 com.komttukttak.app 폴더를 지우면 됩니다.

설치 파일은 GitHub Releases 에서 바로 받아집니다. 파란 창이 뜨면 위 3단계로 넘기세요.
