개인정보처리방침

컴뚝딱 앱과 이 웹사이트가 개인정보를 어떻게 다루는지 적었습니다. 짧은 이유는 다루는 정보가 거의 없기 때문입니다.

시행일 2026-10-01

1. 컴뚝딱이 받아 가는 개인정보: 없습니다

  • 회원가입·로그인·이메일 입력이 없습니다. 이름, 연락처, 계정 정보를 받지 않습니다.
  • 앱이 읽는 PC 사양·디스크 상태 등 검사 결과는 내 PC 화면에 표시됩니다. 파일로 남는 것은 사용자가 직접 고른 폴더·USB 에 저장할 때뿐입니다. 검사 결과를 서버로 보내는 코드가 없습니다.
  • 외부 광고망·방문자 추적 스크립트는 앱과 사이트 어디에도 넣지 않았습니다. 앱 안에는 운영자가 직접 올리는 안내 배너가 나올 수 있습니다(아래 2-(4)). 앱에는 사용자가 동의한 경우에만 켜지는 익명 사용 통계가 있습니다(아래 2-(3)). 동의하지 않으면 아무것도 보내지 않습니다.

2. 앱이 인터넷에 접속하는 경우

앱이 인터넷을 쓰는 경우는 아래 다섯 가지뿐입니다. (1)·(2)·(4)는 파일을 내려받기만 하고, (3)은 사용자가 동의했을 때만 어떤 기능을 썼는지를 보내며, (5)는 사용자가 로그인한 자기 구글 드라이브에 사용자가 누른 파일만 올리고 받습니다.

(1) 새 버전이 있는지 확인할 때

앱을 실행하면 새 버전이 있는지 GitHub Releases(github.com)에 한 번 확인합니다. 이 요청은 일반 웹 접속과 같아서, 접속한 IP 주소·요청 시각이 GitHub 서버 로그에 남을 수 있습니다. 이 로그는 GitHub 가 GitHub 개인정보 보호 정책에 따라 관리하며, 컴뚝딱은 이 로그를 받지도 볼 수도 없습니다.

  • 요청에 담기는 것: 없습니다. 앱은 GitHub 에 올라간 버전 목록 파일(latest.json)을 내려받아 PC 안에서만 비교합니다. 앱 버전·PC 사양·검사 결과는 보내지 않습니다.
  • 오프라인이면 업데이트 확인만 건너뛰고 앱은 그대로 동작합니다.

(2) 포토샵 도우미의 아이콘·스티커 팩을 받을 때

포토샵 도우미에서 아이콘 목록을 열면, 새 아이콘이 있는지 GitHub(raw.githubusercontent.com)에서 목록 파일 하나를 확인하고 바뀐 그림 파일만 내려받아 내 PC 안에 저장합니다. 아이콘 목록을 한 번도 열지 않으면 이 접속은 일어나지 않습니다. (포토샵 도우미는 준비 중인 기능입니다. 기능을 공개하기 전에 이 절을 먼저 적어 둡니다.)

  • 요청에 담기는 것: 프로그램 이름을 뜻하는 고정 문자열(komttukttak-assets) 하나뿐입니다.
  • 담기지 않는 것: 앱 버전, PC 이름, 설치 번호, 검사 결과, 그리고 어떤 아이콘을 골랐는지. 쿠키도 쓰지 않습니다. 앱은 없는 그림을 받아 올 뿐이라 고른 아이콘이 무엇인지는 서버가 알 수 없습니다.
  • 다만 (1)과 마찬가지로 일반 웹 접속이라, 접속한 IP 주소와 요청 시각이 GitHub 서버 로그에 남을 수 있습니다. 이 로그도 GitHub 가 관리하며 컴뚝딱은 받지도 볼 수도 없습니다.
  • 받은 그림은 내 PC 의 %APPDATA%\com.komttukttak.app\assets 폴더에만 저장되고, 그 폴더를 지우면 함께 없어집니다.
  • 인터넷이 없거나 접속이 막혀 있으면, 이미 받아 둔 아이콘과 앱에 들어 있는 기본 아이콘으로 그대로 쓸 수 있습니다.

(3) 사용 통계 — 동의한 경우에만

컴뚝딱을 더 쓸모 있게 만들려고, 어떤 기능이 많이 쓰이는지 알고 싶습니다. 그래서 처음 실행할 때 "사용 통계를 보내도 될까요?" 를 묻고, [보내도 돼요]를 누른 경우에만 아래 내용을 보냅니다. [안 보낼래요]를 누르거나 답하지 않으면 아무것도 보내지 않습니다.

  • 보내는 것: 동의할 때 새로 만드는 무작위 설치 번호(이름·PC·계정과 연결되지 않는 임의의 글자), 앱 버전, Windows 10/11 구분, 연 화면의 이름(예: 파일 복구하기), 쓴 기능의 이름과 성공 여부·걸린 시간(초), 앱 안의 안내 배너를 보거나 누른 것, 그리고 그 시각.
  • 보내지 않는 것: 이름·이메일·연락처, PC 이름·계정 이름, 파일·폴더 이름과 경로, 사진·문서 내용, 검사 결과(PC 사양·디스크 상태·설치 프로그램 목록), 하드웨어 일련번호. 앱은 정해 둔 항목 이름과 짧은 영문 값만 통과시키고 나머지는 보내기 전에 버립니다.
  • 받는 곳: 컴뚝딱 운영자가 직접 관리하는 통계 서버(국내 웹호스팅 카페24). 다른 회사의 분석 서비스로 보내지 않습니다. 서버는 IP 주소를 저장하지 않으며, 받은 기록에서도 정해 둔 항목 이름과 짧은 영문 값만 남기고 나머지는 버립니다. 다만 일반 인터넷 접속처럼 호스팅 업체의 접속 로그에 IP 주소와 시각이 잠시 남을 수 있습니다.
  • 쓰는 곳: 하루에 몇 명이 쓰는지, 어떤 기능을 많이 쓰는지, 배너를 몇 명이 누르는지 같은 전체 숫자를 보고 무엇을 먼저 만들지 정하는 데만 씁니다. 다른 곳에 팔거나 광고에 쓰지 않습니다.
  • 보관: 최대 1년이 지난 기록은 지웁니다.
  • 끄는 법: 앱 왼쪽 메뉴 맨 아래 [사용 통계 보내는 중]을 누르면 바로 꺼집니다. 끄는 순간 아직 보내지 않은 기록은 버리고 설치 번호도 지워서, 다시 켜더라도 이전 기록과 이어지지 않습니다.

(4) 앱 안 안내 배너를 받을 때

앱의 홈 화면과 왼쪽 메뉴 아래에 컴뚝딱과 관련 서비스를 알리는 배너가 나올 수 있습니다. 앱은 켜질 때(그 뒤로는 10분에 한 번) 운영자가 관리하는 서버(국내 웹호스팅 카페24)에서 배너 목록을 확인하고, 그림·영상은 배너마다 한 번만 내려받아 내 PC 에 둡니다.

  • 요청에 담기는 것: 프로그램 이름을 뜻하는 고정 문자열 하나뿐입니다. 설치 번호·PC 정보·검사 결과는 담기지 않습니다.
  • 배너를 보거나 누른 사실은 사용 통계(3)에 동의한 경우에만 셉니다. 동의하지 않았으면 배너는 보이기만 하고 기록되지 않습니다.
  • 배너를 누르면 기본 브라우저로 그 배너의 안내 페이지가 열립니다. 그 페이지에서 무엇을 하는지는 그 사이트의 방침을 따릅니다.
  • HTML 로 만든 배너는 앱과 분리된 칸(샌드박스)에서 열려 앱이나 내 PC 의 정보에 접근할 수 없습니다.
  • 일반 인터넷 접속처럼 호스팅 업체의 접속 로그에 IP 주소와 시각이 잠시 남을 수 있습니다. 받은 그림은 %APPDATA%\com.komttukttak.app\banners 에만 저장되고, 그 폴더를 지우면 함께 없어집니다.

(5) 구글 드라이브 보관함 — 사용자가 로그인한 경우에만

포토샵 도우미의 [구글 드라이브] 탭에서 사용자가 직접 구글 계정으로 로그인한 경우에만, 사용자가 누른 파일을 그 사용자의 구글 드라이브에 올리고 받습니다. 파일은 앱과 구글 사이에서만 오가며 컴뚝딱 서버를 거치지 않습니다.

  • 권한: 구글의 drive.file 권한 하나만 요청합니다. 앱이 직접 올린 파일만 보고 받을 수 있고, 드라이브의 다른 파일은 목록도 내용도 볼 수 없습니다. 올린 파일은 드라이브의 '컴뚝딱' 폴더에 모입니다.
  • 앱이 구글에서 읽는 것: 계정 이름·이메일(화면 표시용), 드라이브 전체 용량과 사용량(남은 용량 게이지), 앱이 올린 파일의 이름·크기·날짜·미리보기 그림. 이 정보는 화면에 보여 주기만 하고 컴뚝딱이나 다른 곳으로 보내지 않습니다.
  • 올릴 때: 사용자가 고른 파일과, 포토샵 문서면 드라이브 미리보기로 쓸 작은 그림 한 장을 함께 올립니다.
  • 비밀번호는 구글 로그인 화면(브라우저)에만 입력하며 앱은 보지 않습니다. 로그인을 유지하는 열쇠는 Windows 의 사용자별 암호화(DPAPI)로 잠가 %APPDATA%com.komttukttak.appgdrive.dat 에 두고, [로그아웃] 을 누르면 지우고 구글 쪽 권한도 끊습니다. 받은 미리보기 그림은 같은 폴더의 gdrive-thumbs 에만 둡니다.
  • 구글에서 받은 정보는 위 기능에만 쓰며, 광고·분석·제3자 제공에 쓰지 않습니다 (Google API 서비스 사용자 데이터 정책의 제한적 사용 요건 준수). 구글 계정의 타사 앱 권한에서도 언제든 끊을 수 있습니다.

3. 교실 PC 사양 일괄 확인

선생님이 교실 PC 여러 대의 사양과 설치 프로그램을 한 표로 보도록, PC 마다 리포트 파일(PC이름.json)을 하나씩 만듭니다. 앱의 [리포트 저장] 버튼이나, 앱이 만들어 주는 모으기.cmd(설치 없이 더블클릭)로 만들며 두 방법의 파일 항목은 같습니다.

리포트 파일에 담기는 것

  • PC 이름(컴퓨터 이름)과 수집 시각
  • 내부 IP 주소 1개 — 공유기·학교망 안에서 쓰는 주소(예: 192.168.0.101)
  • CPU 이름·코어 수·스레드 수, 메모리 총량
  • 그래픽카드 이름 (원격 제어 프로그램이 만든 가상 화면 장치 이름이 있으면 따로 표시)
  • Windows 이름·버전·빌드 번호·32/64비트 구분
  • 저장장치: 드라이브 문자, 드라이브 이름(볼륨 이름 — 사용자가 붙인 이름이면 그 이름), SSD/HDD 구분, 전체·남은 용량
  • 설치 프로그램 목록: 프로그램 이름·버전·게시자·설치 날짜·크기, 모든 사용자용인지 로그인한 계정에만 설치됐는지, Windows 구성 요소·업데이트인지 여부. Windows "설치된 앱" 목록과 같은 곳에서 읽기 때문에 그 PC 에 로그인한 계정에만 설치한 프로그램(예: 게임·메신저)도 포함됩니다.
  • 파일 형식 정보: 리포트 형식 버전, 만든 방법(앱 / 모으기.cmd)

담기지 않는 것

  • 로그인한 사용자 계정 이름, 도메인 이름
  • MAC 주소, 기기·디스크·BIOS 일련번호, 기기 고유 ID
  • 파일·문서의 이름과 내용, 사진, 화면
  • 인터넷 사용 기록, 브라우저 정보, 비밀번호

저장 위치 · 전송 · 삭제

  • 리포트는 선생님이 고른 폴더(교실 공유 폴더 또는 USB)에만 저장됩니다. 모으기.cmd 는 그 폴더 안의 reports 하위 폴더에만 쓰며, 이 폴더가 없으면 아무것도 저장하지 않고 멈춥니다. 앱의 [리포트 저장]은 선생님이 고른 폴더에 바로 씁니다.
  • 앱과 모으기.cmd 모두 인터넷으로 보내는 코드가 없습니다. 앱은 그 폴더의 파일을 읽어 표로 보여 줄 뿐 다른 곳에 복사하지 않습니다. 앱이 기억하는 것은 마지막으로 고른 폴더 경로와 찾아본 프로그램 이름뿐입니다.
  • 공유 폴더에 두면 그 폴더를 열 수 있는 사람은 리포트도 열어 볼 수 있습니다. 폴더 권한은 앱의 수집 화면 "자세히" 안내를 따라 정해 주세요.
  • 지우는 법: 폴더(reports 하위 폴더 포함)에서 리포트 파일을 지우면 끝입니다. 따로 남는 사본이 없습니다.
  • 학생 PC 정보를 모으는 기능이므로 학교·학원 관리자가 PC 점검 목적으로만 사용해 주세요.

4. 파일 복구하기

  • 고른 드라이브를 읽기 전용으로 열어 지운 파일을 찾습니다. 드라이브를 직접 읽으려면 [스캔 시작] 때 Windows 가 관리자 권한을 한 번 묻고, 권한을 받은 도우미 프로그램은 같은 PC 안에서만 앱과 통신합니다(네트워크 없음).
  • 스캔 결과(찾은 파일 이름·경로·크기·지운 시각 추정)와 미리보기는 PC 메모리에만 있고 파일로 저장하지 않습니다. 앱을 닫으면 사라집니다.
  • 복구한 파일은 사용자가 고른 폴더에만 새 파일로 만들어집니다. 그 폴더는 원본과 다른 디스크여야 하며, 원본 드라이브에는 쓰지 않습니다.
  • 복구한 파일은 원래 파일 내용 그대로라 개인정보가 들어 있을 수 있습니다. 필요 없어지면 직접 지워 주세요.

5. 이 웹사이트

  • 사이트는 GitHub Pages 에서 호스팅됩니다. GitHub 는 서비스 운영·보안을 위해 접속 로그(IP 주소, 브라우저 종류, 요청 시각·주소)를 일시 보관할 수 있습니다. 자세한 내용은 GitHub 개인정보 보호 정책을 보세요. 이 로그는 GitHub 가 관리하며 컴뚝딱이 받지도 볼 수도 없습니다.
  • 사이트가 쓰는 글꼴·아이콘 파일은 모두 이 사이트에서 직접 제공합니다. 외부 CDN 접속이 없습니다.
  • 홈 첫 문장을 두 가지 중 하나로 보여 주기 위해 브라우저 저장공간(localStorage)에 한 글자(A 또는 B)를 저장합니다. 이 값은 브라우저 밖으로 나가지 않으며, 브라우저 데이터를 지우면 함께 지워집니다. 쿠키는 쓰지 않습니다.
