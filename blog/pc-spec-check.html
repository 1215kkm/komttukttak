내 PC 사양 확인하는 법 — 윈도우 기본 기능 4가지 (3초 만에 한 화면으로 보는 법까지)

2026-09-14 컴뚝딱내 PC 사양 보기

게임 사양 되는지 물어보려는데 내 컴퓨터 사양을 모른다.
중고로 팔려고 글 쓰는데 그래픽카드 이름을 어디서 보는지 모르겠다.
수리기사님이 "사양 좀 알려주세요" 하는데 화면 어디를 봐야 할지 막막하다.

셋 중 하나면 이 글로 끝납니다. 먼저 윈도우에 이미 들어 있는 방법부터, 설치 없이.

1. 윈도우 기본 기능으로 PC 사양 확인하기 (무료·설치 없음)

방법 1. 설정 → 정보 — CPU·RAM·윈도우 버전

Win + I → 시스템 → 정보. 프로세서(CPU), 설치된 RAM, 윈도우 에디션·버전·OS 빌드가 나옵니다. 그래픽카드는 여기 없습니다.

방법 2. dxdiag — 그래픽카드까지

Win + R → dxdiag 입력 → 엔터. '시스템' 탭에 CPU·메모리, '디스플레이' 탭에 그래픽카드 이름과 메모리. 게임 사양 물을 때 가장 많이 쓰는 화면입니다.

방법 3. msinfo32 — 메인보드·바이오스

Win + R → msinfo32. 시스템 요약에 메인보드 제조사·모델, BIOS 버전까지. 램 추가하려고 슬롯 확인할 때 씁니다.

방법 4. 작업 관리자 → 성능 — SSD인지 HDD인지

Ctrl + Shift + Esc → 성능 탭. 왼쪽 '디스크'를 누르면 SSD/HDD 종류, '메모리'를 누르면 속도(MHz)와 슬롯 사용 개수. 위 세 방법엔 없는 정보입니다.

정리하면 CPU·RAM은 어디서든 보이지만, 그래픽카드는 dxdiag, 메인보드는 msinfo32, SSD 여부는 작업 관리자 — 네 군데를 돌아야 다 모입니다. 캡처해서 보내려면 네 장이죠.

2. 네 군데 돌기 번거로우면 — 컴뚝딱

컴뚝딱은 무료 PC 유틸 모음이고, '내 PC 사양 보기'를 켜면 CPU·RAM·그래픽카드·저장장치(SSD/HDD)·윈도우 버전·IP·PC 이름이 한 화면에 나옵니다. 설치 파일 하나, 회원가입 없음, 결과는 내 PC 밖으로 나가지 않습니다.

  • 텍스트로 복사 → 카톡·게시판에 그대로 붙이기
  • 이미지 카드로 복사 → "내 사양 봐줘" 글에 캡처 네 장 대신 한 장

첫 버전을 준비하고 있습니다. GitHub Releases 알림을 켜 두면 올라오는 날 GitHub 알림으로 옵니다. 이메일은 받지 않습니다.

출시 알림 받기 설치 안내
  • 회원가입 없음
  • 광고 없음
  • 검사 결과는 내 PC 안에만

3. 저장장치가 'HDD'로 나왔다면

사양 보기엔 위험 판정이 없습니다. 다만 저장장치 칸이 HDD(하드디스크)이고 5년 넘게 쓴 PC라면, 같은 앱 안의 'HDD 건강검진'(출시 예정)을 한 번 돌려 보세요. 결과는 🟢🟡🔴 세 가지로 나오고, 🟡은 "중요 파일 백업부터" 안내만, 🔴일 때만 복구업체 견적 버튼이 보입니다. 겁주는 문구 없이, 디스크가 스스로 기록한 SMART 값(디스크 건강 수치) 그대로입니다.
