하드디스크 배드섹터 확인하는 법 — chkdsk부터 SMART까지 (윈도우 기본 기능, 무료)

2026-09-14 컴뚝딱HDD 건강검진

파일을 열면 "데이터 오류(순환 중복 검사)"가 뜬다.
탐색기가 특정 폴더에서 멈추고, 복사 하나에 30분이 걸린다.
부팅이 예전보다 눈에 띄게 오래 걸린다.

배드섹터(디스크에서 읽고 쓸 수 없게 된 구간) 초기 증상일 수 있습니다. 확인하는 법을 쉬운 것부터 순서대로.

시작 전 한 줄 — 이상한 소리가 나면 검사하지 마세요

하드에서 '틱틱', '끼릭' 소리가 반복되면 아래 검사를 돌리지 마세요. 헤드·모터 같은 물리 손상이면 검사 자체가 디스크를 더 상하게 합니다. 전원을 끄고 바로 맨 아래 4번 🔴 항목으로 가세요.

1. 드라이브 속성 → 오류 검사 (가장 쉬움)

탐색기 → 드라이브 우클릭 → 속성 → '도구' 탭 → 오류 검사 '검사'. 파일 시스템 오류만 잡아 주고, 배드섹터 전체 스캔은 아닙니다. 가볍게 한 번 보는 용도.

2. chkdsk /r — 배드섹터 전체 스캔

시작 → cmd 검색 → 관리자 권한으로 실행 후

chkdsk D: /f /r

/f는 파일 시스템 오류 수정, /r은 배드섹터를 찾아 읽을 수 있는 데이터를 옮깁니다. C: 드라이브는 재부팅 후 실행됩니다. 1TB 하드면 2~4시간. 결과 마지막 줄의 "KB(불량 섹터)"가 0이 아니면 배드섹터가 있는 겁니다.

주의: chkdsk는 디스크에 '쓰기'를 합니다. 이미 파일이 안 읽히는 상태라면 먼저 3번으로 상태만 보고, 중요 파일을 백업한 뒤에 돌리세요.

3. PowerShell로 SMART 상태 보기 — 쓰기 없이 읽기만

Windows PowerShell을 관리자로 실행하고

Get-PhysicalDisk | Select FriendlyName, MediaType, HealthStatus

HealthStatus가 Healthy면 정상, Warning이나 Unhealthy면 디스크가 스스로 경고 중입니다. 더 자세히 보려면

Get-PhysicalDisk | Get-StorageReliabilityCounter | Select DeviceId, Temperature, ReadErrorsUncorrected, Wear

ReadErrorsUncorrected가 0이 아니면 못 읽은 구간이 있었다는 뜻입니다. 이벤트 뷰어(Win + R → eventvwr) → Windows 로그 → 시스템에서 원본 'disk' 이벤트 7·51·153이 반복되면 같은 신호입니다.

그래도 번거로우면 — 컴뚝딱 HDD 건강검진 (출시 예정)

명령어 외우기 싫으면 컴뚝딱의 'HDD 건강검진'(출시 예정). 버튼 한 번(관리자 권한은 그때만 묻습니다) → SMART·온도·수명·위험도를 🟢🟡🔴 카드로 보여 줍니다. 디스크를 읽기만 하고 절대 쓰지 않습니다. 무료, 결과는 내 PC 안에만.

컴뚝딱 받기

설치 파일 4.5MB. 실행하면 바로 'HDD 건강검진'.

무료로 받기 설치 안내
  • 회원가입 없음
  • 광고 없음
  • 검사 결과 인터넷 전송 없음

4. 결과별로 할 일 (과장 없이)

  • 🟢 정상: 할 일 없습니다. 6개월에 한 번만 다시 보세요.
  • 🟡 주의: 지금 고장은 아니지만 수치가 나빠지는 중입니다. 중요 파일부터 다른 드라이브나 클라우드에 백업하세요. 그 이상은 필요 없습니다.
  • 🔴 위험: 디스크가 "곧 실패할 수 있음"을 스스로 기록한 상태(SMART 예측 실패)입니다. 오늘 죽는다는 뜻은 아니지만, 이 순서로 움직이세요.
    1. 이 디스크에 새로 저장·chkdsk·조각 모음을 하지 않는다.
    2. 사진·문서처럼 다시 못 만드는 파일부터 다른 드라이브로 복사한다.
    3. 복사 중 안 읽히는 파일이 있거나 소리가 난다면 — 소프트웨어로는 안 됩니다. 물리 복구 업체 영역이고, 앱 🔴 화면의 [복구업체 견적 받기]로 견적을 먼저 비교하세요. 시세가 보통 수십만 원대라 두세 곳은 받아 보는 게 맞습니다.
